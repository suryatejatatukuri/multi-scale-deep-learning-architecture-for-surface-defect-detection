# Dataset Instructions

This project uses images to train and validate a deep learning model for surface defect detection.

## Folder Structure

```text
dataset/
├── train/
│   ├── Defective/
│   └── Non-Defective/
└── val/
    ├── Defective/
    └── Non-Defective/
```

## Instructions

- Place images of defective surfaces in the `Defective` folders.
- Place images of non-defective surfaces in the `Non-Defective` folders.
- Use separate images for training and validation.
- Supported image formats include JPG, JPEG, and PNG.
- Ensure images are relevant to the surface defect detection task.
